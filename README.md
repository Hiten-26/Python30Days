# Python30Days

This repository documents my progress through the [30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python) challenge.

I started this challenge to build my confidence in Python and get more comfortable writing code consistently. Rather than just watching tutorials or relying on solutions, I wanted to practice properly, work through problems myself, and keep a record of what I’ve learned.

## Why I’m doing this

I’m interested in building a stronger career in data and analytics and beyond, and Python is a skill I want to develop properly. This challenge is a way for me to improve my foundations, stay consistent, and show my progress over time.

I’m using this repository to keep myself accountable and to document the journey day by day. The aim isn’t to be perfect, it’s to keep learning, keep practicing, and get better as I go.

## What’s in this repo

This repo includes my work from each day of the challenge, including exercises, notes, and practice files covering core Python concepts.

## Note

This is a learning repository, so it reflects my progress as I go rather than finished or polished projects.
